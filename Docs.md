# GOOGLE DOCS

## 1. Introduction

Google Docs is a free, web-based word-processing application developed by Google. It allows users to create, edit, format, and share documents online.

Unlike traditional offline word processors, Google Docs supports real-time collaboration, allowing multiple users to work on the same document simultaneously.

Documents are saved automatically to Google Drive.

## 2. Features of Google Docs

- Online document creation and editing.
- Real-time collaboration.
- Automatic saving.
- Cloud-based storage using Google Drive.
- Sharing documents through links.
- Commenting and suggesting features.
- Version history.
- Spell-checking and grammar suggestions.
- Insertion of tables, images, charts, and links.
- Downloading documents in different formats.

## 3. Creating a Document

The following steps are used to create a document:

1. Open Google Docs.
2. Sign in using a Google account.
3. Select Blank Document or choose a template.
4. Enter the required content.
5. Format the text using the toolbar.
6. Insert images, tables, and other elements if required.
7. The document is automatically saved to Google Drive.

Website: https://docs.google.com

## 4. Important Formatting Features

| Feature | Description |
|---|---|
| Font Formatting | Changes font type, size, and colour |
| Paragraph Alignment | Aligns text left, right, centre, or justified |
| Line Spacing | Controls spacing between lines |
| Headings | Organizes content into sections |
| Page Setup | Controls margins, page size, and orientation |
| Tables | Organizes information into rows and columns |
| Insert Image | Adds images to documents |
| Hyperlinks | Connects text to external websites or resources |

## 5. Collaboration Features

One of the most important features of Google Docs is real-time collaboration.

### Sharing

Users can share documents with others by entering their email addresses or generating a sharing link.

### Permission Levels

Google Docs provides three major permission levels:

- **Viewer:** Can only view the document.
- **Commenter:** Can view and add comments.
- **Editor:** Can modify the document.

### Comments

Users can add comments to specific portions of a document to provide suggestions or feedback.

### Suggesting Mode

Suggesting mode allows users to propose modifications without directly changing the original content. The document owner can accept or reject these suggestions.

## 6. Version History

Google Docs maintains a history of changes made to a document.

It allows users to:

- View previous versions.
- Identify modifications.
- Restore an older version.
- Check changes made by collaborators.

This feature is useful when multiple people are working on the same document.
